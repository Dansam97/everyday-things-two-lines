A tiny Python program that writes a two-line explanation of a traffic jam for a 10-year-old: line 1 builds the picture on one concrete analogy (a giant zipper made of cars), and line 2 honestly says what that analogy maps and what it leaves out.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
